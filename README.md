## 数据与方法

数据来自 Mendeley Data Version 1（DOI：10.17632/2nxpvtz935.1，CC BY 4.0）。
对应研究为 Bean、Pojani 和 Corcoran（2021），Journal of Transport Geography，95:103155。
完整日度面板包含 29 个城市、10,578 个城市日；全期关联分析使用 25 个城市、
9,120 个城市日；预测评估使用 23 个城市、8,393 个城市日。

三个层级 Student-t 模型共同包含天气和季节项。M0 使用周末效应，M1 使用完整星期效应
与城市线性趋势，M2 在 M1 基础上加入城市 AR(1) 残差过程。

## 主要结果

- 降雨从城市中位数增加 10 mm，M2 下 `1 + usage` 的条件中位数平均变化为 −20.21%，
  95% 可信区间为 [−21.37%，−18.99%]。25 个城市的关联均为负。
- UTCI 增加 10 °C 的全期关联在 M0 与 M2 下均为正，峰值位置随规格变化。
- M2 在两个开发窗口的块预测 WIS 最低。最终窗口 M0 为 0.1957，M2 为 0.3394，
  M0 表现更好；90% 区间覆盖率分别为 75.5% 和 60.5%。

这些结果描述观测关联。预测使用已知天气；期中的全期探索性分析曾接触年末观测。
最终窗口结果按预先设定的评估方案报告，不能直接解释为因果效应或业务预报能力。
